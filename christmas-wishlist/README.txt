Preview:
Open index.html in a browser. An internet connection is needed for the Google Fonts and remote product/style photos.

Publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html, styles.css and script.js (keep them together in the repository root).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will provide a public website link after deployment.
